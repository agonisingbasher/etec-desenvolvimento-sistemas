# Sistema de Monitoramento de Reservatório de Água 💧

Atividade correspondente à Agenda 11 da disciplina de Desenvolvimento de Sistemas I.

## Objetivo
Desenvolver um sistema em Python executado via terminal para monitorar os níveis de um reservatório de água. O sistema alerta o usuário mudando a cor das mensagens de acordo com a gravidade do nível da água.

## Tecnologias e Bibliotecas Utilizadas
- **Python 3**
- **Colorama:** Para estilização e coloração das saídas no terminal.
- **Time:** Para simular o delay de leitura dos sensores.

## Como executar
1. Clone este repositório.
2. Certifique-se de ter o Python instalado na sua máquina.
3. Instale a biblioteca colorama executando no terminal:
   `pip install colorama`
4. Execute o arquivo principal:
   `python main.py`
