## 🎯 Sobre o Projeto

Desenvolvido para o ambiente de caixa de uma loja online, este programa em **Python** automatiza o cálculo de descontos progressivos com base no valor total da compra efetuada pelo cliente, exibindo um cupom fiscal detalhado ao final.

---

## 📋 Regras de Negócio Implementadas

O sistema utiliza estruturas condicionais para definir a porcentagem do desconto de forma otimizada:

* **Compras abaixo de R$ 200,00:** Desconto de **5%**
* **Compras de R$ 200,00 até R$ 299,99:** Desconto de **10%**
* **Compras a partir de R$ 300,00:** Desconto de **15%**

---

## ⚙️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Conceitos aplicados:** Estruturas de decisão (`if`, `elif`, `else`), operadores relacionais, formatação de saída (`:.2f`) e tratamento de exceções (`try/except`).
